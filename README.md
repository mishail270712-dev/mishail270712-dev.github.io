# Симулятор казино

Современное веб-приложение "Симулятор казино" с визуально впечатляющим UI и серверной логикой.

## Технологии
- Frontend: HTML, CSS (SCSS), JavaScript (ES6+)
- Backend: Node.js + Express
- База данных: JSON-файл
- Без внешних фреймворков

## Функциональность
1. Регистрация / вход пользователя
2. Игровая валюта: виртуальные "фишки"
3. 3 различных игры: Слоты, Блэкджек, Кости
4. Система ставок
5. История игр
6. Leaderboard
7. Анимации и звуки
8. Dark Mode

## Установка и запуск
```bash
npm install
node backend/server.js
